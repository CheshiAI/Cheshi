# 프로젝트 시작하기

프로젝트는 함께 작업할 파일이 들어 있는 폴더입니다. Workspaces에서 새로 만들거나 기존 폴더와 저장소를 열 수 있습니다.

## 언제 쓰나요

새 작업을 시작하거나 다른 프로젝트로 이동할 때 사용합니다. 빈 프로젝트를 만들려면 Create project, 컴퓨터에 있는 폴더는 Open folder, 원격 저장소를 가져오려면 Clone repository를 선택합니다.

## 어떻게 하나요

1. Workspaces를 엽니다.
2. 새 프로젝트는 하단의 **Create project**를 누릅니다. **Browse**로 상위 폴더를 선택하고 **Project name**에 새 이름을 입력합니다.
3. 생성될 경로를 확인하고 **Create and open**을 누릅니다. 같은 이름의 파일이나 폴더가 이미 있으면 다른 이름을 사용합니다.
4. 기존 프로젝트는 **Open folder**에서 프로젝트 폴더 자체를 선택합니다.
5. 원격 저장소는 **Clone repository**에서 저장소를 선택하거나 **Repository URL**을 입력합니다. **Parent folder**와 **Folder name**을 확인한 뒤 **Clone and open**을 누릅니다.

## 결과는 무엇인가요

프로젝트가 Workspaces에 등록되고 새 창에서 열립니다. 처음 여는 프로젝트는 코드 분석 준비에 시간이 걸릴 수 있습니다.

Create project는 새 폴더에 Git 저장소를 초기화합니다. 첫 커밋과 원격 저장소는 자동으로 만들지 않습니다. Open folder는 선택한 기존 폴더로 작업하고, Clone repository는 원격 저장소를 컴퓨터로 복제합니다.

프로젝트 생성이나 복제는 완료됐지만 창 열기에 실패한 경우 **Open in new window**로 다시 열 수 있습니다. 완료된 폴더를 다시 만들 필요는 없습니다.

## 여러 프로젝트를 한 창에서 작업하기

EXPLORER 상단의 **Add project to workspace**로 기존 프로젝트 폴더를 추가합니다. 예를 들어 `cheshi`와 `cheshi-flash`를 별도 루트로 펼치고 같은 SESSION 대화에서 작업할 수 있습니다. 연결 목록은 창을 다시 열어도 유지됩니다.

파일 검색은 연결된 프로젝트를 함께 찾습니다. Git 화면에서는 프로젝트를 선택하고, 터미널의 새 세션 메뉴에서는 시작할 프로젝트를 선택합니다. 터미널 분할은 원래 세션의 프로젝트 경로를 사용합니다. 각 저장소의 Git 기록과 배포 설정은 독립적으로 유지됩니다.

연결 목록을 바꾸려면 진행 중인 대화 작업이 끝날 때까지 기다립니다. 변경된 목록은 다음 대화 턴에 반영되며 선택한 권한 모드는 유지됩니다. CodeGraph는 프로젝트별 기존 인덱스를 사용하고, 프로젝트 추가만으로 새 인덱스를 만들지 않습니다.

프로젝트 행의 메뉴에서 **Remove from workspace**를 선택하면 연결만 해제합니다. 실제 폴더와 파일은 삭제되지 않으며 열린 편집 내용과 터미널은 유지됩니다. 해제한 프로젝트의 파일을 다시 저장하려면 프로젝트를 재연결합니다. 최초 프로젝트는 해제할 수 없고, 서로 포함되는 폴더는 중복 연결할 수 없습니다. 한 워크스페이스에는 최초 프로젝트를 포함해 최대 16개를 연결할 수 있습니다.
