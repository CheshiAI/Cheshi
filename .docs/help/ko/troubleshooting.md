# 문제 해결

문제가 생긴 화면의 오류 문구를 확인하면 다음에 해야 할 작업을 찾기 쉽습니다.

## 언제 쓰나요

로그인, 프로젝트 열기, AI 응답, 파일 복원 또는 Git 작업이 완료되지 않을 때 참고합니다.

## 어떻게 하나요

1. **로그인이나 시작 준비가 안 될 때:** 앱에 표시되는 CLI 설치와 로그인 안내를 완료합니다. 브라우저 인증을 진행했다면 앱으로 돌아와 연결 상태를 확인합니다.
2. **프로젝트가 열리지 않을 때:** 폴더가 실제로 존재하고 접근 가능한지 확인합니다. 생성·복제 완료 메시지가 보이면 **Open in new window**로 다시 열거나 Workspaces의 **Open folder**로 해당 폴더를 선택합니다.
3. **AI 응답이 실패할 때:** 오류 문구와 계정 연결, 인터넷 연결을 확인합니다. 전송 실패로 입력 내용과 첨부가 복구됐다는 안내가 보이면 입력창을 확인한 뒤 다시 보냅니다. Temporary chat에서 모델을 불러오지 못했다면 필요한 내용을 복사한 후 닫고 다시 엽니다.
4. **첨부가 안 될 때:** 파일이 이동·삭제되지 않았는지 확인하고 **Attach files**로 다시 선택합니다. 첨부 처리 중에는 완료될 때까지 기다립니다.
5. **로컬 기록 복원이 안 될 때:** 에디터의 미저장 내용을 먼저 저장합니다. **Refresh local history**로 목록과 현재 파일을 갱신하고 다시 비교합니다. 현재 파일과 동일한 기록은 복원할 필요가 없습니다.
6. **커밋이 안 될 때:** 저장된 변경을 **STAGED**에 넣고 **Commit message**를 입력했는지 확인합니다. 작성자 정보 오류가 나오면 Git의 이름과 이메일 설정을 확인합니다.
7. **푸시가 안 될 때:** 원격 저장소 연결과 Git 인증, 해당 저장소의 쓰기 권한을 확인합니다. AI 계정 로그인과 원격 Git 저장소 접근 권한은 별개입니다. 원격 변경으로 거절됐다면 그 변경을 먼저 확인해야 합니다.

## 결과는 무엇인가요

원인을 해결한 뒤 실패한 작업을 다시 시도할 수 있습니다. 다시 실패하면 오류 문구, 수행한 작업, 앱 버전과 운영체제를 정리하면 문제를 재현하고 설명하는 데 도움이 됩니다.

오류를 공유할 때는 비밀번호, 토큰, 개인 파일 내용이 포함됐는지 확인합니다. 작업 중인 파일이나 프로젝트 폴더를 지우는 방식으로 재시도할 필요는 없습니다.
