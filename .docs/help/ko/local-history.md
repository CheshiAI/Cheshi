# 이전 내용 복원하기

Local history는 이 컴퓨터에 보관한 파일의 과거 내용을 현재 저장된 파일과 비교하고 복원하는 기능입니다.

## 언제 쓰나요

저장한 내용을 되돌리거나 Git에 커밋하지 않은 이전 내용을 찾을 때 사용합니다. 지원되는 텍스트 파일을 열거나 저장하면 기록을 보관하며, 앱이 감지한 외부 변경도 기록합니다.

## 어떻게 하나요

1. 탐색기의 파일 또는 에디터의 파일 탭을 오른쪽 클릭하고 **Local history**를 선택합니다. 에디터의 기록 아이콘으로도 열 수 있습니다.
2. 왼쪽 목록에서 확인할 시점을 선택합니다. **Saved**는 저장한 내용, **Original contents**는 처음 보관한 내용, **External change**는 외부 변경을 감지했을 때의 내용입니다.
3. 왼쪽 **Selected snapshot**은 선택한 시점의 기록입니다. 바로 직전 버전이라는 뜻은 아닙니다. 오른쪽 **Current saved file**은 현재 디스크에 저장된 파일이며 미저장 편집 내용은 포함하지 않습니다.
4. 차이를 확인한 뒤 **Restore this version**을 누릅니다. 미저장 편집 내용이 있으면 먼저 에디터에서 저장합니다.
5. 비교한 뒤 다른 프로그램이 파일을 바꿨다면 갱신된 내용을 다시 확인하고 복원합니다.

## 결과는 무엇인가요

선택한 기록의 내용으로 파일을 복원합니다. 복원 직전의 현재 내용도 기록하므로 다시 이전 상태를 찾아갈 수 있습니다. Git 커밋과 브랜치는 그대로이며, 복원된 파일은 Git에서 변경 파일로 표시될 수 있습니다.

기록은 프로젝트 밖의 Cheshi 사용자 데이터에 보관합니다. 기본 한도는 워크스페이스당 최대 30일, 100 MiB이며 오래된 기록부터 정리합니다. 원격 백업은 아닙니다.

앱이 닫혀 있을 때의 중간 변경이나 기록을 시작하기 전 내용은 복구할 수 없습니다. 이미지 등 바이너리 파일, 삭제된 파일의 재생성, 프로젝트 전체 복원은 지원하지 않습니다. 이름을 바꾼 파일의 이전 기록은 이전 경로에 남습니다.
