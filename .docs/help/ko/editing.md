# 파일 편집하기

탐색기에서 파일을 열고 내용을 수정한 다음 컴퓨터의 파일에 저장합니다.

## 언제 쓰나요

문서나 코드를 직접 수정하거나 AI가 변경한 내용을 확인할 때 사용합니다.

## 어떻게 하나요

1. 탐색기 **EXPLORER**에서 폴더를 펼치고 편집할 파일을 엽니다.
2. 에디터 탭의 파일 이름과 경로를 확인합니다.
3. 텍스트를 수정합니다. 저장하지 않은 변경이 있으면 탭에 표시되고 파일 정보에 **Modified**가 나타납니다.
4. **Save** 아이콘을 누르거나 macOS에서는 **⌘S**, Windows와 Linux에서는 **Ctrl+S**를 누릅니다.
5. 오류가 표시되면 안내를 확인합니다. 외부 프로그램이 같은 파일을 수정했다면 현재 파일 내용을 확인한 뒤 저장을 다시 진행합니다.

## 결과는 무엇인가요

저장에 성공하면 변경 내용이 실제 파일에 반영됩니다. 지원되는 텍스트 파일은 Local history에도 기록되어 이전 내용과 비교할 수 있습니다.

저장은 Git 커밋이나 푸시를 수행하지 않습니다. 작업을 Git 이력에 남기려면 별도로 Commit을 실행합니다. 이미지나 편집을 지원하지 않는 파일은 텍스트처럼 수정할 수 없습니다.
