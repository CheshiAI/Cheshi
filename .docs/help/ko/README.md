# 앱 도움말 관리

한국어 도움말 원본은 이 디렉터리(`.docs/help/ko/`)의 Markdown 파일입니다.
영문 문서는 `../en/`에서 같은 파일 이름으로 관리합니다.
도움말을 수정하거나 번역할 때 두 언어 문서를 모두 유지합니다. 앱은 두 언어를 모두 포함하고 표시합니다.
기본 언어는 영어입니다. 하단 상태바 오른쪽의 Languages 메뉴에서 영어와 한국어를 선택하면
도움말 탐색 메뉴, 검색 안내, 주제 요약, 문서 본문이 함께 바뀝니다.
선택한 언어는 로컬에 저장됩니다. 이 설정은 도움말에 적용되며 앱 전체를 번역하지는 않습니다.
문서에 나오는 메뉴 이름은 실제 앱의 버튼과 일치하도록 유지합니다.
언어를 바꿔도 선택한 문서와 검색어는 유지됩니다. 검색은 선택한 언어의 목록과 문서 본문을 대상으로 합니다.
각 문서는 소개, 사용 시점, 실행 단계, 결과 순서로 작성합니다.
실제 앱의 메뉴 이름을 사용하고, 지원하지 않는 동작이나 아직 구현되지 않은 기능은 안내하지 않습니다.

Renderer는 `desktop/frontend/src/features/help/helpArticles.ts`를 통해 문서 원본을 텍스트로 가져옵니다.
Vite가 문서를 빌드 결과에 포함하므로 설치된 앱은 저장소 경로나 인터넷 연결 없이 도움말을 표시합니다.
문서 수정은 다음 앱 빌드에 반영됩니다. 이미 배포된 앱의 도움말이 자동으로 갱신되지는 않습니다.

새 문서를 추가할 때는 `helpArticles.ts`에 가져오기를 추가하고 `helpCatalog.ts`에 두 언어의
고유 ID, 목록 제목, 소개, 검색어, 관련 문서 ID를 등록합니다.
언어 간 문서 ID와 파일 이름을 일치시킵니다. 도움말 화면의 번역 문구는 `helpTranslations.ts`에서 관리합니다.
문서 본문도 검색 대상입니다. 현재 도움말은 이미지나 링크 이동 없이 텍스트 문서를 표시합니다.
이 Markdown 원본은 향후 공개 문서 사이트에서도 사용할 수 있습니다.

저장소 루트에서 실행하는 검증 명령:

```sh
bun test desktop/test/help-center.test.tsx
bun run viewer:typecheck
bun run viewer:build
```
