# AI와 작업하기

프로젝트에 관한 질문과 요청을 대화로 전달하고, 필요한 파일이나 이미지를 함께 첨부할 수 있습니다.

## 언제 쓰나요

코드를 이해하거나 오류를 살펴보고, 파일 수정 작업을 요청할 때 사용합니다. 예를 들어 “이 프로젝트를 실행하는 방법을 설명해 줘”처럼 원하는 결과를 구체적으로 적습니다.

## 어떻게 하나요

1. 프로젝트를 열고 대화를 선택하거나 새 대화를 시작합니다.
2. 입력창에서 사용할 모델과 추론 수준을 확인한 뒤 질문을 적습니다.
3. 클립 모양의 **Attach files**를 눌러 파일이나 이미지를 첨부합니다. 일반 대화 입력창에는 외부 파일이나 앱의 탐색기 파일을 드래그해서 넣을 수도 있습니다.
4. 입력창에 표시된 첨부 목록을 확인합니다. 잘못 선택한 파일은 해당 항목의 제거 버튼으로 뺍니다.
5. 보내기 버튼을 누릅니다. 응답과 작업 결과를 확인하고 추가 질문으로 이어갑니다. 작업 중 확인이나 입력을 요청하면 내용을 읽고 응답합니다.

## 결과는 무엇인가요

선택한 대화에서 답변과 작업 진행 상황을 확인할 수 있습니다. 파일을 수정하는 요청을 했다면 에디터나 Git 변경 화면에서 실제 변경 내용도 살펴봅니다.

대화 목록에 남기지 않을 질문은 대화 목록의 **Temporary chat** 버튼으로 시작합니다. 임시 대화 안에서도 후속 질문과 파일 첨부가 가능하지만, 창을 닫으면 해당 대화가 끝나며 채팅 기록에서 다시 열 수 없습니다. 필요한 답변은 닫기 전에 복사해 둡니다.


## 이전 대화 찾기

**Settings → TypeSafe API**에서 전송 안내를 읽고 **Allow history recall**을 켠 뒤
워크스페이스를 다시 여세요. 기존 API 키가 있는 사용자도 기본값은 꺼짐입니다.
키 저장이나 연결 검사만으로 켜지지 않습니다. “지난번 계정 전환 작업을 중단한 이유는?”처럼 질문할 수 있습니다.

이 설정은 나중에 여는 워크스페이스를 포함해 모든 워크스페이스에 공통 적용됩니다.
허용하면 에이전트가 검색을 요청한 워크스페이스 안의 다른 대화도 검색할 수 있습니다.
각 검색이 다른 워크스페이스의 대화까지 검색하는 것은 아닙니다.
검색 질문, 후보 대화 본문, 제목과 앞뒤 메시지를 TypeSafe의 Jev로 보냅니다.
Jev를 사용할 수 없거나 키가 없으면 같은 검색 자료를 Codex 로그인으로 OpenAI의 Luna low에 보냅니다.
찾은 원문은 에이전트에도 전달됩니다. 검색어가 겹치는 후보 페이지에 무관한 후보를 채워 넣지 않으며,
다음 페이지에서는 표현이 다른 의미상 관련 후보도 찾을 수 있습니다.

스위치를 끄면 모든 워크스페이스에서 진행 중인 검색을 취소하고 기존 연결의 검색·원문 읽기도 즉시 차단합니다.
이미 전송한 내용은 회수할 수 없습니다. 로컬 기록 탐색은 계속 사용할 수 있습니다.
Jev 요청과 고정 예문을 보내는 연결 검사는 TypeSafe 이용량을 사용하며 Luna는 Codex 계정을 사용합니다.

## 스킬에서 Jev 사용하기

명시적으로 실행한 스킬은 Jev의 yes/no로 분기하고, Jev를 사용할 수 없으면 Luna low로 폴백할 수 있습니다.
스킬이 제공한 판단 입력을 전송하며 이전 대화 검색 스위치와는 별개입니다.
현재 실행기는 소스 체크아웃의 CLI에서 사용합니다. [실행 가능한 스킬 안내](../../skill-flow/ko/guide.md)를 참고하세요.
