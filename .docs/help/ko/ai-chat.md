# AI와 작업하기

프로젝트에 관한 질문과 요청을 대화로 전달하고, 필요한 파일이나 이미지를 함께 첨부할 수 있습니다.

## 언제 쓰나요

코드를 이해하거나 오류를 살펴보고, 파일 수정 작업을 요청할 때 사용합니다. 예를 들어 “이 프로젝트를 실행하는 방법을 설명해 줘”처럼 원하는 결과를 구체적으로 적습니다.

## 어떻게 하나요

1. 프로젝트를 열고 대화를 선택하거나 새 대화를 시작합니다.
2. 입력창에서 사용할 모델과 추론 수준을 확인한 뒤 질문을 적습니다.
3. 클립 모양의 **Attach files**를 눌러 파일이나 이미지를 첨부합니다. 일반 대화 입력창에는 외부 파일이나 앱의 탐색기 파일을 드래그해서 넣을 수도 있습니다.
4. 입력창에 표시된 첨부 목록을 확인합니다. 잘못 선택한 파일은 해당 항목의 제거 버튼으로 뺍니다.
5. 보내기 버튼을 누릅니다. 응답과 작업 결과를 확인하고 추가 질문으로 이어갑니다. 작업 중 확인이나 입력을 요청하면 내용을 읽고 응답합니다.

## 결과는 무엇인가요

선택한 대화에서 답변과 작업 진행 상황을 확인할 수 있습니다. 파일을 수정하는 요청을 했다면 에디터나 Git 변경 화면에서 실제 변경 내용도 살펴봅니다.

대화 목록에 남기지 않을 질문은 대화 목록의 **Temporary chat** 버튼으로 시작합니다. 임시 대화 안에서도 후속 질문과 파일 첨부가 가능하지만, 창을 닫으면 해당 대화가 끝나며 채팅 기록에서 다시 열 수 없습니다. 필요한 답변은 닫기 전에 복사해 둡니다.
