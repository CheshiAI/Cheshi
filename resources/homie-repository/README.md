# {{HOMIE_NAME}}

이 호미만의 비공개 설정 저장소입니다.

- `agent.json`: 이름, 역할, 모델, 도구 정의와 실행 환경
- `instructions.md`: 호미의 기본 작업 지침
- `skills/<name>/SKILL.md`: 스킬과 해당 스킬에서 참조하는 파일
- `scripts/`, `resources/`: 도구 스크립트와 추가 자료

Cheshi에서 호미를 생성하면 이 저장소를 준비하고 로컬에 가져와 Explorer에 연결합니다.
초기 파일은 Cheshi 프로젝트의 생성 스크립트와 템플릿으로 작성됩니다.
기본 생성 위치는 로그인한 GitHub 계정이며, 조직 선택은 해당 계정의 로컬 설정에만 저장됩니다.
저장소 이름은 `homie-호미이름`을 사용하고, 원격 이름이나 로컬 폴더가 겹칠 때만 식별자를 붙입니다.
재시도와 이름 변경은 처음 연결한 저장소를 재사용하며, 기존 파일은 덮어쓰지 않습니다.

로컬 저장소 파일이 설정의 원본입니다. Explorer에서 파일을 저장한 뒤
호미 설정의 **Apply changes**를 누르거나 워커를 시작하면 검증 후 적용됩니다.
작업 중인 워커는 중단하지 않으며, 잘못된 설정은 적용되지 않습니다.
프로젝트 공통 규칙은 작업 프로젝트 루트의 `AGENTS.md`에서 관리합니다.
저장 후 적용하거나 워커를 시작하면 최신 내용을 읽습니다. 추가 지침 입력과 MD 연결은 사용하지 않습니다.
과거 추가 지침이 남아 있으면 값을 보존하고 실행을 차단하므로, 파일로 이전한 뒤 기존 설정을 비워야 합니다.
도구 변경 후에는 새 대화를 시작해야 합니다. Git 커밋과 푸시는 별도로 수행합니다.
`resources.files`에는 파일 경로를 기록할 수 있으며, 위 세 폴더의 파일도 자동으로 읽습니다.
`resources.programs`에는 필요한 Debian 패키지를 지정합니다.
`requestedPermissions`는 요청 사항이며 로컬에서 허용한 권한을 확대하지 않습니다.
계정 인증 정보, 프로젝트 할당, 대화, 실행 기록과 작업 프로젝트 소스는 포함하지 않습니다.
