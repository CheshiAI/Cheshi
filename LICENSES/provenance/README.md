# Upstream grammar build records

These documents and patches are preserved from CodeGraph's upstream repository
without modifying their contents. Their source commits and URLs are recorded in
[../SOURCES.json](../SOURCES.json). The CodeGraph
[MIT notice](../../codegraph/LICENSE) applies to the upstream additions;
the original grammar notices remain in [../cobol.LICENSE](../cobol.LICENSE) and
[../vbnet.LICENSE](../vbnet.LICENSE).

The paths, package-manager commands, test results, and upstreaming status in
these historical documents describe the upstream CodeGraph checkout at the
recorded commit. They are not commands to run in the Cheshi repository root or
new verification results for Cheshi. Their `src/extraction/wasm/` corresponds to
Cheshi's `codegraph/src/extraction/wasm/`.

The patch files are source artifacts for rebuilding the inherited grammars;
they are not changes applied to Cheshi during publication preparation. They are
kept intact, including patch context and whitespace.
